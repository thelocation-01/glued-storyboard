# Contributing

Thank you for improving Glued Storyboard.

1. Create a focused branch from `main`.
2. Do not commit `.env` files, downloaded models, project data, generated media, or renders.
3. Run `pnpm install --frozen-lockfile` and `pnpm verify`.
4. Describe the visible behaviour, verification performed, and any Windows-specific assumptions.
5. Keep the local-first privacy model and stable-motion design intact unless the change explicitly proposes a new mode.

Bug reports should include the Windows version, Node/Python versions, the failing step, and a redacted error message. Never attach API keys, private scripts, copyrighted media, or customer projects.
